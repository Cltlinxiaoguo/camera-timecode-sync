# 相机同步检测工具 v1.0.0

## 变更摘要

- 首个公开发布版本。
- Windows 单文件可执行程序（PyInstaller），GUI 默认无控制台窗口。
- 流程：清空 JPG 中间目录 → CR2 转 JPG（可配置裁剪）→ PaddleOCR 时间码识别 → Excel 报告（含同步率与饼图）→ 复制不同步样本至归档目录。

## 使用提示

- 将 **`相机同步检测工具.exe`** 与 **`camera_sync_config.yaml`** 放在同一文件夹后运行。
- 首次 OCR 可能需联网下载模型至用户目录下的 `.paddleocr`；离线请从已跑通环境拷贝该目录。

## 系统要求

- Windows 10/11 x64  
- 若缺少 VC++ 运行库，可能需要安装 *Microsoft Visual C++ 可再发行组件*（x64）
